## Summary

Adds a Multi-Asset & Oracle Configuration Guide and links it from the deployment guide and incident runbook (Issue #402).

- `docs/MULTI_ASSET_AND_ORACLES.md` (new):
  - Token onboarding checklist for SAC / SEP-41 assets: `add_allowed_token`, multisig auth, sharded allowlist, the "empty allowlist = allow all" bootstrap behaviour, and off-chain checks for rebasing / fee-on-transfer / third-party-pausable tokens.
  - Decimal normalization and dust-floor guidance: raw base units, 1e7 fixed-point rates, 7/6/18-decimal examples, and `set_min_split_amount`.
  - Oracle configuration: `OracleRateConfig` fields, `set_oracle_rate_config`, staleness checks and error codes in `refresh_conversion_rate`, and the `set_conversion_rate` manual fallback (including `enabled = false` behaviour).
  - Honest scope note: there is no TWAP/deviation-band circuit breaker in `set_oracle_rate_config`, no per-token decimals field, no FX rate snapshotted onto payments, and no FX conversion in refund settlement. The refund circuit breaker monitors volume, not price; the only real rate lock is the escrow swap `locked_rate`.
  - Escrow token swaps: `configure_escrow_swap` / `execute_escrow_swap`, MEV rate lock, 300-second oracle age limit, 1e7 output scaling and slippage guard.
  - Multi-currency refund settlement via the refund token registry and `original_token`.
  - Safe delisting checklist for `remove_allowed_token` and `deregister_refund_token`, including the empty-list bypass and in-flight payments/escrows.
  - Concrete Testnet `stellar contract invoke` commands for whitelisting, oracle config/refresh, swaps and the refund registry.
- `docs/DEPLOYMENT.md`, `docs/OPERATIONAL_RUNBOOK.md`: links to the new guide.

All entrypoint signatures, storage keys, error codes and line references were verified against `core/contracts/payment`, `core/contracts/escrow` and `core/contracts/refund`.

## Summary

Adds a new `services/crank-worker/` TypeScript service that executes permissionless Soroban
lifecycle transitions on a schedule: scheduled payments, recurring subscriptions, metered
billing, dunning retries, trial conversion notices, merchant payouts, payment expiry,
arbitration timeouts and stale-escrow cleanup.

- `src/scheduler.ts` selects due tasks from indexed PostgreSQL schedules
  (`next_run_at <= now + lookahead`) and claims distributed locks keyed by
  `(contract, entity_id, action_type)` so horizontal replicas never submit duplicates.
- `src/pipeline.ts` is simulate-first: no signature and no `sendTransaction` happens unless
  simulation succeeds. Already-executed and deterministically reverting tasks are skipped
  without paying gas. TTL-expired state is restored with `restoreFootprint` and re-simulated.
- Channel accounts with managed sequence numbers, `tx_bad_seq` refetch and transaction polling
  are implemented in `src/rpc/stellar.ts`.
- Outcomes, tx hashes, gas and next retry timestamps are persisted in PostgreSQL; transient RPC
  failures use short retries while deterministic reverts go through per-subscription dunning
  backoff and a store-backed circuit breaker.
- Prometheus metrics: due queue depth, execution latency, gas per action type and permanently
  failing jobs.

Also adds the SQL schema, service README, root README section, `make crank-*` targets and a
Node job in CI. No Rust contract code was changed.
